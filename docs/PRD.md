## 2. 产品概述

### 2.1 背景与目标

香港大学 MSc(Eng) Innovative Design and Technology（IDT，创新设计与技术，26 级）为授课型硕士项目（TPG）。学生在选课季需要在数十门 List A/List B 课程中完成满足毕业学分结构的组合，并兼顾上课时间冲突、通勤安排与校历节点。官方信息分散在课程大纲、Excel 课表、学年日历等多个来源，查询成本高。

本产品将上述信息整合为一个移动优先的 H5 单页应用，提供：

- 课程库浏览、搜索、筛选与本机评价；
- 一键选课并自动同步上课时间到每周课表，自动检测时间冲突；
- 毕业学分结构自动核算；
- 2026-27 校历节点日历；
- 深圳-香港大学跨境通勤攻略。

产品目标：让 IDT 学生在 10 分钟内完成一版无冲突、满足学分要求的选课方案。

### 2.2 目标用户

| 用户画像 | 核心诉求 |
| --- | --- |
| 全日制 TPG 学生 | 快速了解课程内容与评价，排出无冲突课表 |
| 在职兼读学生 | 优先筛选晚间（19:00 后）与周末班次 |
| 深圳跨境通勤学生 | 结合口岸时间选择上课时段，查询通勤路线 |
| 26 级新生 | 了解 26 级课程变更（新增课程、List 调整、学分新规） |

### 2.3 产品形态

| 形态 | 说明 |
| --- | --- |
| H5 SPA（主形态） | Vite 5 构建、无框架原生 JS、Hash 路由；托管于 GitHub Pages，base 路径 `/hku-idt-guide/` |
| 微信小程序（附属） | `miniprogram/` 目录，原生 WXML/WXSS，功能为 H5 的子集（无选课联动、无课表下载卡片、无浏览量统计），本 PRD 以 H5 为准 |

### F5 选课与课表联动（核心流程）

**功能描述**：点击「+ 选课」后自动把官方课表中的学期、星期、起止时间、地点、课程代码/名称、教师、班次同步写入每周课表；退课时同步清除。实现于 `src/utils/enroll.js`。

**主流程**：

```
点击「+ 选课」(enrollCourse)
  ├─ 无固定时间班次(0 个) → 仅加入选课，Toast「已加入选课(该课程暂无固定上课时间)」
  ├─ 1 个班次 → 直接进入冲突检查
  └─ 多个班次 → 弹出班次选择弹窗(radio 列表：Sem/班次/星期时间/场地/教师)
        └─ 确定选课 → 进入冲突检查
冲突检查(commitEnroll)
  ├─ 无冲突 → 写入选课 + 课表时段，Toast「已选课,时间已同步到课表」
  └─ 有冲突 → 弹出「上课时间冲突」确认弹窗
        ├─ 列出每条冲突时段(红色：代码 星期 时间 @地点)与冲突课程代码+中文名
        ├─ 确认「取代旧课程」→ 移除冲突课程的选课与全部课表时段，再写入新课
        └─ 取消「保留原课表」→ 不选课，Toast「已取消,课表未变动」
```

| 编号 | 功能点 | 需求说明 |
| --- | --- | --- |
| F5-1 | 冲突判定规则 | 同一天（day 相同）且时间区间重叠（`!(endA<=startB || startA>=endB)`）且学期兼容：任一方无 term（手动添加时段）视为两学期都占用，均冲突；双方有 term 时仅同学期冲突 |
| F5-2 | 班次选择 | 多班次时必须弹窗选择，默认选中第一项；选项文案 `Sem 1 · 1A · 周一 19:00-21:50 · CYCC501 · 教师名` |
| F5-3 | 时段写入 | slot 字段：code、term、section、day(1-7，周一=1)、startMin、endMin、location(venue)、instructor |
| F5-4 | 退课联动 | 「已选 ✓」点击退课：移出选课列表并删除该课程代码下全部课表时段，Toast「已移出选课,课表时段同步删除」 |
| F5-5 | 取代范围 | 确认取代时，冲突课程的「选课记录 + 全部时段」一并移除（含该课其它不冲突时段） |

**验收标准**：单班次课选课后课表立即出现对应块；同日同学期重叠必弹冲突框且列出冲突课程中文名；取消取代后课表与选课均无变化。

## 5. 数据需求

### 5.1 数据源与治理

| 数据 | 来源 | 更新机制 |
| --- | --- | --- |
| 课程库 COURSES | HKU 官方《MSc(Eng) & MSc, Faculty of Engineering 选课课程清单 2026-27 Sem1》PDF | 坐标级解析后编程生成 `src/data/courses.js` |
| 排课 TIMETABLE | HKU 官方《2026-Sem1-Engg.pdf 全院第一学期课程时间表》（27 页） | 坐标级解析后编程生成 `src/data/timetable.js`；跨页冲突以开课院系页为准 |

冲突处理原则：课程存在性与基础属性以课程大纲为准；开课学期、班次、时间、场地、教师以最新版官方课表 Excel 为准。

### 5.2 静态数据模型

**COURSES**（`src/data/courses.js`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | string | 课程代码（主键），如 COMP7506 |
| title / titleZh | string | 英文名 / 中文名 |
| list | 'A' \| 'B' \| 'capstone' | 课程分类 |
| credits | number | 学分 |
| semester | '1' \| '2' \| '1&2' \| 'TBD' | 开课学期（TBD = 本学年无排课数据） |
| cef | boolean | 是否 CEF 可报销 |
| isNew2026 / movedToB2026 | boolean | 26 级新增 / 26 级转 List B 标记 |
| desc / prereq / exclusive | string | 简介 / 先修要求 / 互斥课程 |

**TIMETABLE**（`src/data/timetable.js`，`{ [code]: Section[] }`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| term | 1 \| 2 | 学期 |
| section | string | 班次号，如 1A、2C |
| day | 'MON'..'SUN' \| '' | 星期（空 = 无固定上课时间） |
| start / end | 'HH:mm' \| '' | 起止时间 |
| venue | string | 场地（可空） |
| instructor | string | 教师（可空，多人分号分隔） |

**DEGREE_RULES**：total 72、courseCredits 48、listAMin 24、disciplineMin 36、electiveMax 12、dissertation 24。

### 5.3 本机持久化（localStorage）

| Key | 结构 | 说明 |
| --- | --- | --- |
| `idt_selection` | `string[]` | 已选课程代码列表 |
| `idt_slots` | `Slot[]` | 课表时段；Slot = { id, code, term?, section?, day(1-7), startMin, endMin, location, instructor? }；无 term/section 的为手动添加时段 |
| `idt_reviews` | `{ [code]: Review[] }` | 课程评价；Review = { id, rating(1-5), nickname, content, ts } |

读写均带 try/catch 兜底（隐私模式等 localStorage 不可用时返回默认值，不抛错）。

## 7. 技术与部署约束

- 技术栈：Vite 5 + 原生 JavaScript（ES Module）+ 原生 CSS，无 UI 框架。
- 路由：Hash 路由（GitHub Pages 无服务端重写能力）。
- 托管：GitHub Pages，`base: '/hku-idt-guide/'`；静态资源（官方课表 xlsx）放 `public/` 随构建进入站点根。
- 部署流水线：`npm run build` → `git push`（main 分支源码）→ `npx gh-pages -d dist`（发布分支）→ CDN 约 45 秒后生效。
- 本机网络约束：访问 GitHub 需经本地代理 127.0.0.1:7897。
